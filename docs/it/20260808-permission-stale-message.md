# 权限请求取消后的消息生命周期

## 背景

审批请求通过 Bubble Tea 消息队列送入 TUI。turn 被 Esc 或 Ctrl+C 取消时，broker 会先取消等待中的请求，但已经排入 UI 队列的请求消息仍可能稍后抵达；如果直接渲染，会出现无法再决策的“幽灵审批”提示。

## 本轮变更

- broker 增加 pending 状态检查。
- TUI 收到审批消息时，只接收仍由 broker 等待的请求。
- 取消后抵达的旧消息被静默丢弃，避免显示不能生效的审批卡片。
- 增加 broker 生命周期测试，验证取消会移除 pending waiter。

## 行为边界

本轮只处理取消与消息投递之间的竞态；正常 FIFO 审批、多请求排队和已完成决策的行为保持不变。
