# Iteration 20260808: workspace file editing

## Goal

补齐主流 code agent 的最小“读代码、改代码、再运行验证”闭环。本轮只引入一个受工作区约束的精确文件编辑工具，保持现有 ReAct、thread 账本和 TUI 工具事件链不变。

## Reference behavior

Codex CLI、Claude Code 等产品都把文件修改作为独立工具能力，而不是要求模型通过任意 shell 拼接重定向命令。这里采用更保守的第一步：工具接收 `path`、`old_string`、`new_string`，要求旧文本精确匹配一次；多匹配或上下文过时就返回错误，让 agent 重新读取文件后再尝试。

## Changes

- 新增 `edit_file` 工具，使用临时文件写入后原子替换，保留原文件权限。
- 路径必须是工作区相对路径；拒绝 `..` 越界、绝对路径和符号链接文件。
- 工作区复用 `tools.run_command.working_dir`，未配置时使用进程当前目录。
- 注册到默认 ReAct 工具集，并纳入工具状态展示与测试。
- 更新 README、示例配置和本迭代记录。
