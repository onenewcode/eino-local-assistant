# 迭代：查看项目规则文件

日期：2026-08-08

## 背景

状态栏只显示项目规则摘要，恢复旧 session 时还可能显示 `rules=stale`。用户需要一个低成本方式确认当前实际加载了哪些 `AGENTS` 文件，避免把摘要误认为规则详情。

## 实现

- 新增 TUI `/rules` 命令，并加入斜杠菜单、帮助文本和 busy 状态下的即时只读命令集合。
- 命令按系统提示词使用的 broad-to-local 顺序列出非空规则文件的实际路径。
- 空规则文件不显示；超过 128 KiB 的规则文件仍在启动时拒绝。
- 命令只报告加载来源，不把规则正文写入 transcript，避免在 UI 中重复暴露完整项目指令。
