# CLI Project Instruction Init

本轮恢复 `eino init [path]`，提供与主流 Code Agent 项目指令工作流一致的安全起点：在工作区创建可编辑的 `AGENTS.md`，而不是将约定藏在一次性的 shell 参数中。

## 行为

- `eino init` 在当前目录创建最小 `AGENTS.md`；`eino init path/to/AGENTS.md` 使用调用方明确指定的目标。
- 模板给出代码审查、用户改动保护、敏感信息与交付验证的通用约定，项目维护者可据实际语言、工具与规则继续编辑。
- 创建使用独占文件语义。目标已经存在、父目录缺失或不是目录时，命令失败且绝不覆盖或修改已有规则文件。
- 命令不读取模型配置、不启动模型、不创建 session，也不修改既有 workspace 文件。

## 验证

- CLI 测试覆盖 root/help、默认路径、显式路径、模板内容、重复执行拒绝覆盖与不存在父目录的错误。
- 交付前执行 `git diff --check`、`go test ./...`、`go build ./...` 与 `go tool golangci-lint run ./...`。
