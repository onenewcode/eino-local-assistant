# CLI fork command

本轮增加独立的交互式 `fork [session-id]` 子命令，对齐 Codex CLI 从 shell 直接分支历史并进入 TUI 的工作流。仓库原有 TUI `/fork` 和 `exec --fork-session` 已具备底层语义，本轮将启动入口统一到同一个 durable fork helper，避免不同入口产生不同 metadata 或标题规则。

## 行为

- `eino-assistant fork <session-id>` 从指定 thread 的已完成可见历史创建独立 child，并直接在 TUI 中打开 child。
- `eino-assistant fork --last` 按当前 `--cd` workspace 选择最近会话；`--last --all` 显式允许跨 workspace，并包含升级前缺少 workspace metadata 的会话。
- `--title` 可指定 child 标题；省略时使用 `Fork of <父标题>`，父标题为空则回退到父 session ID。
- 支持与 `resume` 相同的 `--model`、`--cd`、permission、risk、sandbox、workspace、max-step 和 `--no-alt-screen` runtime 覆盖。child metadata 记录本次 model/workspace，历史 system prompt 仍继承父 thread。
- parent 有 active turn 时沿用 store 的安全边界拒绝 fork，不隐式 recover、cancel 或修改父账本。
- model、工具、MCP 和 compactor 初始化成功后才创建 durable child，避免启动配置失败留下未使用的分支。
- 当前没有交互式 session picker，因此省略 ID 时必须显式给出 `--last`；这是 Codex picker 工作流的精简子集。

## 验证

测试覆盖 help、ID/`--last`/`--all` 组合、合法 selector 进入 TTY 边界、显式 child 标题、runtime model/workspace metadata，以及 fork 前后父 revision 不变。既有 exec fork 端到端测试继续覆盖默认标题、完整父历史继承和 child 新 turn 提交。
