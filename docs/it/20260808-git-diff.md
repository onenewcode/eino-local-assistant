# Iteration 20260808: read-only git diff

## Goal

补齐代码修改后的审阅闭环，让 agent 能在不调用任意 shell 的情况下查看工作树或 staged diff，并把变更结果继续交给模型和 TUI 展示。

## Changes

- 新增工作区受限的 `git_diff` 只读工具。
- 支持完整工作树 diff、staged diff 和单个相对路径筛选。
- 使用 `git -C ... diff --no-ext-diff -- ...`，不经过 shell，不修改仓库。
- 限制输出默认 64 KiB、最大 1 MiB，并返回 `truncated` 元数据。
- 接入默认工具 registry，增加真实 git 仓库测试和越界路径测试。
- 更新 README 和工具状态清单。
