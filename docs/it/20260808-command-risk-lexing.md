# 命令风险分类词法扫描

## 背景

此前 `ClassifyCommand` 通过字符串包含关系判断风险，容易把引号中的示例文本误判为高风险，也无法区分重定向、命令替换和普通参数。

## 本轮变更

- 增加轻量 shell 词法扫描，识别引号、转义、命令分段和常见操作符。
- 将重定向、命令替换和反引号替换标记为高风险。
- 对 `rm`、`git reset/clean/restore`、`sudo` 等危险命令按词元判断，避免匹配普通字符串。
- 多命令组合默认保持 medium；单个无操作符的只读命令才标记 low。

## 边界

这仍然只是权限提示的保守分类，不是 shell 解析器、沙箱或安全策略替代品。未知语法和未覆盖的 shell 特性继续落到 medium，并由实际权限模式决定是否允许执行。
