# 工具结果 warning 可观测性

## 背景

`run_command` 将非零退出、超时、取消和输出截断作为模型可处理的软结果返回，这是 agent 循环需要的行为。但此前 TUI 对所有非工具错误结果都使用成功卡片，用户无法快速区分“命令执行完成”和“命令完成但需要关注”。

## 本轮变更

- 增加 `warn` 工具卡片状态，使用 `⚠` 标记。
- `run_command` 的 `exit_code != 0`、`timed_out`、`cancelled` 或 `truncated` 会显示 warning。
- 仍然把原始结构化结果交给模型，不改变软失败和后续恢复逻辑。
- 其他工具继续使用原有 `ok` / `err` 状态。

## 边界

warning 只影响 TUI 展示，不等价于权限拒绝，也不会把命令非零退出转换成 Go 工具错误；模型仍可读取完整的结构化字段并决定下一步。
